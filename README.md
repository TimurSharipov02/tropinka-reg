# FGK CloseSeason 26

Сайт закрытия сезона: регистрация до старта и аллейкат по QR-точкам после.

- **До 30.10, 21:00 (МСК)** - описание, цены, регистрация, обратный отсчёт.
  После регистрации - сумма и реквизиты для перевода по СБП и статус оплаты,
  который организатор отмечает галочкой в таблице.
- **С 21:00** - регистрация закрыта; список точек и топ видны всем.
  Вход по нику из Telegram нужен только чтобы сканы засчитывались.
- **QR на точке** - ссылка `https://<сайт>/?cp=<id>&k=<секрет>`. Камера телефона
  открывает сайт, он берёт геолокацию, сервер проверяет секрет и расстояние.
- **Очки** - сумма ценности точек (финиш в клубе - самая ценная).
  При равенстве выше тот, кто набрал очки раньше.

## Файлы

- `index.html`, `style.css`, `app.js` - сайт
- `config.js` - адрес сервера (`apiUrl`); пустой - демо-режим
- `data.js` - демо-данные
- `server/` - сервер на Google Таблице + Apps Script, [инструкция по установке](server/README.md)
- `mockups/` - скриншоты состояний

## Демо

Пока `apiUrl` пустой (или в адресе есть `?demo=…`), сайт работает на демо-данных,
а внизу есть переключатель состояний: `?demo=reg | pay | guest | racer | scan-ok | scan-far | scan-guest`.
