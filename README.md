# FGK CloseSeason 26

Макет сайта закрытия сезона: регистрация до старта и аллейкат по QR-точкам после.

Открыть: `index.html` в браузере. Внизу страницы — переключатель состояний макета
(или `?demo=reg | guest | racer | scan-ok | scan-far | scan-guest`).
Скриншоты всех состояний — в `mockups/`.

## Как устроено

- **До 30.10, 21:00 (МСК)** — описание, цены, форма регистрации, обратный отсчёт.
- **С 21:00** — регистрация закрыта; список точек и топ видны всем.
  Вход по нику из Telegram нужен только чтобы сканы засчитывались.
- **QR на точке** — ссылка `https://<сайт>/?cp=<id точки>&k=<секрет>`.
  Камера телефона открывает сайт, он берёт геолокацию и засчитывает скан,
  если до точки не больше `radius` метров.
- **Очки** — сумма ценности точек (×1…×5, финиш в клубе ×5).
  При равенстве выше тот, кто набрал очки раньше.

## Что сейчас макет

Все данные демо (`data.js`), вход и сканы живут только в браузере.
Для рабочей версии нужен сервер (места помечены в `app.js` как «СЕРВЕР»):
список зарегистрированных ников, приём сканов с проверкой секрета QR,
расстояния и времени, общий топ.
