# Сервер аллейката — Google Таблица + Apps Script

Бесплатно, без хостинга. Все данные лежат в одной Google Таблице:

| Лист | Что там |
|---|---|
| **Настройки** | время старта, радиус засчёта скана, адрес сайта, цены, дата повышения цены, «Гонка только после оплаты» |
| **Регистрации** | кто зарегистрировался с сайта, сколько должен и галочка **«Оплачено»**. В колонке «Допуск» напишите `нет`, чтобы не пускать человека в гонку |
| **Точки** | точки маршрута: название, адрес, координаты, ценность, финиш, секрет, ссылка и картинка QR |
| **Сканы** | журнал всех попыток скана: кто, какая точка, расстояние, статус (`ok`, `далеко`, `неверный код`, …). В топ идут только `ok` |

## Установка (≈10 минут)

1. **Создайте таблицу**: [sheets.new](https://sheets.new), назовите, например, «FGK CloseSeason 26».
2. **Вставьте код**: в таблице «Расширения → Apps Script», удалите всё в редакторе,
   вставьте содержимое файла [`Code.gs`](Code.gs), нажмите 💾.
3. **Создайте листы**: в редакторе сверху выберите функцию `setup` → «Выполнить».
   Google попросит доступ к таблице: «Проверить разрешения» → ваш аккаунт →
   «Дополнительные настройки» → «Перейти в проект» → «Разрешить».
   В таблице появятся листы и меню «Аллейкат».
4. **Опубликуйте сервер**: «Начать развёртывание → Новое развёртывание» →
   тип «Веб-приложение»; «Запуск от имени» — **Я**; «У кого есть доступ» — **Все**.
   Скопируйте URL, который заканчивается на `/exec`.
5. **Подключите сайт**: вставьте этот URL в `config.js` → `apiUrl`.
6. **Опубликуйте сайт** (например, GitHub Pages: Settings → Pages → Deploy from branch)
   и впишите его адрес в «Настройки → Адрес сайта».

## Точки и QR-коды

1. Заполните лист «Точки» (пример-строки замените):
   - **ID** — короткий латиницей, уникальный: `c1`, `bridge`, `fin`…
   - **Широта / Долгота** — в Яндекс Картах: правый клик по месту → «Что здесь?» → координаты
   - **Ценность** — сколько очков даёт точка
   - **Финиш** — `да` у клуба
2. Меню «Аллейкат → Обновить ссылки и QR точек» — у каждой точки появятся секрет,
   ссылка и картинка QR. Картинку можно скопировать/распечатать прямо из таблицы.
3. **После печати не меняйте ID и секреты** — иначе напечатанные коды перестанут подходить.
4. Не делитесь таблицей: в ней секреты QR-кодов.

## Оплата

Участник платит сам переводом по СБП по номеру телефона — без комиссии.
Сумму считает сервер при регистрации: «Цена, ₽», а с даты «Повышение цены» —
«Цена после повышения, ₽»; девушкам — 0 (сразу отмечено «Оплачено»).

1. Сайт показывает участнику сумму, номер и просит указать ник в сообщении к переводу.
2. Видите перевод в приложении банка → ставите галочку «Оплачено» у этого ника.
3. У участника на сайте статус сменится на «оплачено ✓» (кнопка «Обновить статус»
   или при следующем заходе). Во время гонки неоплатившим показывается напоминание.

«Гонка только после оплаты» = `да` — сканы без галочки «Оплачено» не засчитываются.
По умолчанию `нет`, чтобы задержка с отметкой не остановила гонщика на трассе.

## Проверка перед эвентом

Временно поставьте в «Настройки → Старт» прошедшее время, откройте сайт,
отсканируйте напечатанный QR на месте — в «Сканах» появится строка `ok`.
Потом верните время старта и очистите тестовые строки в «Сканах».

## Как это работает

- До старта сервер принимает регистрации и не отдаёт точки.
- С момента старта регистрация закрыта; точки и топ видны всем.
- Вход — по нику из регистрации. Скан засчитывается, если секрет в QR совпал,
  а телефон не дальше радиуса (+ до 50 м на погрешность GPS) от точки.
- Очки = сумма ценности точек; при равенстве выше тот, кто набрал их раньше.
- Изменили `Code.gs`? «Начать развёртывание → Управление развёртываниями» → ✏️ →
  «Версия: новая» — адрес `/exec` останется прежним.
